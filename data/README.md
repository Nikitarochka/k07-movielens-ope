# Данные проекта К07

Источник — [официальный MovieLens 1M](https://files.grouplens.org/datasets/movielens/ml-1m.zip).
Используется тот же срез **K07-ML1M-25to34-v1**, который был подготовлен 25 октября:
контрольные суммы CSV побайтно совпадают с исходным комплектом заявки.

| Файл | Содержание |
|---|---|
| `main_slice.csv` | 383 928 оценок, 1 696 пользователей возрастной группы 25–34 года с не менее чем 40 исходными оценками; 3 499 фильмов |
| `control_slice.csv` | Подмножество основного: 150 отложенных пользователей, по 20 оценённых фильмов, всего 3 000 строк; 1 295 фильмов |
| `slice_manifest.json` | Правила отбора, размеры и SHA-256 исходных и готовых файлов |
| `MovieLens_README.txt` | Исходное описание набора, условия использования и цитирование |

Каждая CSV-строка — наблюдаемая оценка. Поля: `source_row` — номер строки
в исходном `ratings.dat` (с 1); `UserID`, `MovieID` — исходные идентификаторы;
`Rating` — оценка 1–5; `Timestamp` — Unix-время в секундах.

Контрольные пользователи полностью исключаются из расчёта популярности.
Оставшиеся 1 546 пользователей основного среза используются для разработки.
Идентификаторы отложенных пользователей и порядок 20 фильмов каждой задачи
сохранены в [audit_tasks.jsonl](../results/stage1/audit_tasks.jsonl): каждый
`source_rows` задаёт строки исходного MovieLens, по которым задача однозначно
связывается с приложенными CSV. Эталон `target_value` равен среднему индикатору
`Rating >= 4` для первых пяти целевых фильмов этой задачи.

Восстановление данных: `python scripts/build_slice.py --out data` из корня
репозитория. Скрипт проверяет SHA-256 по копии того же манифеста в `scripts/`.
Для обычного запуска скачивание не требуется — оба CSV уже здесь.

Старый ZIP из корня удалён как дубликат: сами CSV, манифест и скрипт сохранены
распакованными. Историческая заявка и её вложения остаются доступны в истории
Git до коммита очистки; карточка проекта находится в `docs/card.md`.
