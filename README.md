# К07 — аудит WIS на MovieLens 1M

## Этап 1 — к 24 ноября

Выполнен базовый аудит WIS при `epsilon = 0.5`: 150 контрольных задач,
100 действий на пользователя, 500 независимых симуляций. Базовая линия —
наивная средняя награда. Результаты и ограничения: [docs/stage1.md](docs/stage1.md).
Уточнённая карточка коллег объединена в проект: [docs/card.md](docs/card.md).
Формулы приведены к Markdown-формату GitHub.

Запуск из корня репозитория, Python 3.10+:

```text
python -m pip install -r requirements.txt
python stage1.py
python -m unittest discover -s tests -v
```

Оба используемых CSV уже сохранены в `data/`; запуск не требует сети.
При необходимости пересобрать их из официального источника:

```text
python scripts/build_slice.py --out data
```

Для локального архива можно добавить `--source /path/to/ml-1m.zip`.
Полные 500 логов не сохраняются из-за повторяющегося объёма: сохранены точные
конфигурации и seed каждого запуска, один пример лога и все результаты.
Передача готовых предсказаний моделей, API-ключи и GPU не нужны.

Файлы этапа 1:

- `stage1.py` — подготовка задач, генерация логов, WIS, baseline и интервалы;
- `configs/stage1.json` — заранее фиксированный протокол;
- `results/stage1/audit_tasks.jsonl` — 150 контрольных задач и точные эталоны;
- `results/stage1/runs.csv` — все 500 независимых запусков;
- `results/stage1/example_log.csv` — один моделируемый лог для проверки формул;
- `results/stage1/metrics.csv` и `summary.json` — метрики и интервалы;
- `results/stage1/error_cases.csv` — пять наибольших ошибок WIS;
- `results/stage1/checks.json` — результаты проверок и повторной сборки.

Интервалы отдельных логов — стратифицированный delta-method; интервалы RMSE
и средней ошибки — bootstrap по независимым симуляциям. Они относятся к
фиксированному контрольному срезу, а не ко всей популяции MovieLens.
Дальнейшие стресс-проверки и защита в этап 1 не включены.
