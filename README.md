# Проект К07 · logs

## Исследовательский вопрос
В каких случаях WIS на контрольном срезе MovieLens 1M существенно ошибается относительно точной ценности целевой политики при уменьшении покрытия её действий логирующей политикой?

## Данные и срез
MovieLens1M; K07-ML1M-25to34-v1: пользователи 25–34 лет с не менее чем 40 оценками. Основной срез — 1 696 пользователей и 383 928 оценок. Контроль — 150 полностью отложенных пользователей, по 20 фильмов на пользователя. Пользователи и фильмы выбраны воспроизводимо по SHA-256 без использования значений Rating.; лицензия: исследовательское использование; ПЕРЕРАСПРОСТРАНЕНИЕ ЗАПРЕЩЕНО

## Эталон и метод
Эталонный исход или прокси: Точный эталон: средняя бинарная награда пяти целевых фильмов каждого пользователя. Награда равна 1 при Rating >= 4 и 0 иначе. Общая эталонная ценность текущего среза — 0.476. Эталон не покрывает неоценённые фильмы, весь каталог и реальный причинный эффект показа рекомендации.
Оцениваемый оценщик: WIS — self-normalized importance sampling. Он оценивает целевую политику по созданному логирующей политикой логу и известным вероятностям действий.
Базовое сравнение: Основное сравнение — WIS при хорошем покрытии, epsilon = 0.5. Дополнительная проверка — наивная средняя награда в логе без коррекции на различие политик.

## Метрика и критерий
Метрика ошибки: RMSE оценки WIS относительно точной эталонной ценности по повторным симуляциям: квадратный корень из среднего квадрата разности между WIS и эталоном. Дополнительно считаются ESS, число целевых событий и доля запусков с нулевой суммой весов.
Численный критерий успеха: Предварительно считать WIS ненадёжным, при ... (например, если RMSE достигает 0.1)

## Риск и границы
Возможная ошибка оценщика: WIS может случайно показать значение рядом с эталоном при очень малом числе целевых событий. Результат также можно искусственно улучшить, если исключать неопределённые запуски, подбирать удачные seed или настраивать политики по контрольным оценкам.
За границами проекта: Не входят обучение моделей, сравнение WIS с IS и DR, второй датасет, неоценённые фильмы, реальный запуск рекомендаций, веб-интерфейс и выводы о качестве рекомендательной системы на всём каталоге MovieLens.
